# Hangman (Terminal Edition)

A terminal-based Hangman game that uses [Rich](https://github.com/Textualize/rich) for colorful layouts and status panels.

## Usage

```bash
pip install .
hangman
```

## Development

- Requires Python 3.10+
- Install dependencies with `pip install -e .`
- Run the game with `python -m hangman_nogui` or the `hangman` console script.

Have fun saving the stick figure!
